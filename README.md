# CodeForge

CodeForge is a placement-oriented coding practice and assessment platform for students.

## Features

- DSA problem practice
- Easy, Medium, and Hard difficulty levels
- Online Java coding
- Test-case based code evaluation
- Coding submissions and history
- Placement coding tests
- Progress dashboard
- DSA roadmap
- Leaderboard and gamification
- AI-powered coding mentor
- Admin panel for managing questions and tests

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Code Execution: Judge0
- AI Mentor: Claude API
- Version Control: Git and GitHub
